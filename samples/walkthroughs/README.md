# Walkthroughs

One per sample game: the commands that play it through, winning where it can be won. `@frotzinc/zmachine`'s differential test plays each sample (every version it's built for) with its walkthrough, in frotzplay's interpreter and in ZVM, with the same seed, and requires the same transcript turn by turn.

They come from [Frotzsmith](https://frotzsmith.com) (`app/modules/samples-shared/*.walkthrough.txt`, at commit `643f61d`), where the same walkthroughs are the samples' Solutions. Format: one command per line (or several separated by `.`); lines starting with `!` are comments. `minimal` has none: it takes no input.
